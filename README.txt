실행
1. ZIP 파일을 먼저 압축 해제하세요.
2. index.html을 Chrome, Edge, Firefox 또는 Safari에서 여세요.
3. 설치·로그인·인터넷 연결은 필요하지 않습니다. 이메일과 LinkedIn 링크를 여는 데에는 인터넷/메일 앱이 필요합니다.

내용 수정
- 상단 파란 영역의 Edit page를 누르세요.
- 항목을 수정하고 Save changes를 누르면 현재 페이지와 해당 브라우저에 저장됩니다.
- Education은 학위별로 줄을 나누고, Skills/Research 방법은 쉼표로 구분하세요.
- 프로젝트·경력·스킬 등 목록은 Add item / Remove로 추가·삭제할 수 있습니다.
- 저장 공간은 브라우저/파일 경로에 따라 달라질 수 있습니다. 브라우저 데이터를 지우거나 파일을 옮기기 전 반드시 백업하세요.

수정한 결과 보관·이동
- Download updated HTML: 사진·디자인·현재 내용이 모두 포함된 새 HTML 파일을 다운로드합니다. 이 파일 하나로 다른 컴퓨터에서도 열 수 있습니다.
- Export JSON backup: 텍스트 내용의 백업 파일을 만듭니다.
- Import JSON: 백업한 내용으로 현재 페이지를 교체합니다.
- Reset to file version: 현재 HTML에 담긴 원본 내용으로 돌아갑니다. 저장하지 않은 변경은 사라집니다.
- 다른 사람에게 공유하려면 Download updated HTML로 만든 파일을 보내세요. 상대방도 내용을 편집할 수 있습니다.
- 발표 사진의 자동 배치는 프로젝트의 위치/주제에 Lao가 포함된 경우에 적용됩니다.

파일 구성
index.html: 실제 실행 파일. 스타일·스크립트·사진이 모두 내장되어 있습니다.
portfolio-data.json: 초기 텍스트 내용의 백업 파일.
styles.css / portfolio.js: 내장된 스타일·스크립트의 개발 참고용 원본. 이 두 파일을 수정해도 index.html은 자동으로 바뀌지 않습니다.
assets/: 원본 사진 두 장. index.html에는 같은 사진이 내장되어 있습니다.

현재 공개 포트폴리오와는 별도입니다. 여기서 수정한 내용은 공개 사이트에 자동 반영되지 않습니다.
